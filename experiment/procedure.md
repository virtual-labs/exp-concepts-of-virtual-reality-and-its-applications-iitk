<b>Note: </b> This is a VR-based experiment, in the simulation, you can learn from scratch how to download the APK and use VR, while the Procedure section explains the actual lab experiment steps as performed in the Virtual Reality (VR) Lab. <br><br>

| **Step** | **Actual Lab Procedure (Physical Microscope)** | **Virtual Reality (VR) Lab Procedure (Simulation)** |
|-----------|-----------------------------------------------|-----------------------------------------------------|
| **1. Setup & Transportation** | Carry the microscope with two hands. Place gently on a lab bench. Plug in the light source. | The user appears in the virtual lab. The virtual scope is ready on the bench. Use the VR Controller to select and click interactive labels for each part (e.g., Nose Piece, Stage, Fine Adjustment) to view its description. |
| **2. Slide Placement** | Lower the mechanical stage. Place the prepared slide onto the stage and secure it with the stage clips. | The user uses the VR Controller's grip button to virtually grab a slide and drag it to the virtual stage, where a socket interactable (as seen in the video) snaps it into the correct position. |
| **3. Initial Focus (Low Power)** | Rotate the Nose Piece to position the Low Power (10x) objective. Look through the oculars and use the Coarse Focus Knob to slowly move the stage downward until the specimen comes into rough focus. | The user points the VR Controller at the virtual Coarse Focus Knob and uses a grip/trigger gesture to rotate the knob, observing the virtual stage move and the image come into focus on the eyepiece overlay. |
| **4. High Power Focus** | Without using the Coarse Knob, rotate to the High Power (40x) objective. Use only the Fine Focus Knob to bring the specimen into sharp, clear focus. | The user rotates the virtual nose piece and then interacts with the Fine Focus Knob, visually confirming the image detail improves in the virtual eyepiece display. |
| **5. Visualizing the Light Path** | (Cannot be performed. This is an abstract, unobservable concept.) | The user clicks the "See Light Path" button (as shown in the video). A virtual red light ray is illuminated, demonstrating how light travels from the source, through the specimen, and up to the eyepiece. |
| **6. Illumination Adjustment** | Adjust the Iris Diaphragm or the light intensity knob (rheostat) to maximize image contrast and brightness. | The user interacts with the virtual intensity knob (as hinted in the video's task list), using a virtual slider on the controller display to change the virtual light intensity and observe the effect on the specimen's illumination. |
