<b>Note: </b> This is a VR-based experiment; in the simulation, you can learn from scratch how to download the APK and use VR, while the Procedure section explains the actual lab experiment steps as performed in the Virtual Reality (VR) Lab. <br><br>

| **Step** | **Actual Lab Procedure (Physical Microscope)** | **Virtual Reality (VR) Lab Procedure (Simulation)** |
|-----------|----------------------------------------------|----------------------------------------------------|
| **1. Setup & Transportation** | Carry the microscope with both hands and place it gently on the lab bench. Plug in the light source. | The user appears in the virtual lab with the microscope ready on the bench. Using the VR controller, they can click each labeled part (e.g., Nose Piece, Stage, Fine Adjustment) to view its description. |
| **2. Slide Placement** | Lower the mechanical stage, place the prepared slide, and secure it with the stage clips. | The user uses the VR controller’s grip to grab and place the slide on the virtual stage, where it snaps correctly into position. |
| **3. Initial Focus (Low Power)** | Rotate the nose piece to position the Low Power (10x) objective. Use the Coarse Focus Knob to bring the specimen into rough focus. | The user points at the virtual Coarse Focus Knob and rotates it using a grip/trigger gesture, observing the stage move and the image come into focus. |
| **4. High Power Focus** | Without using the Coarse Knob, rotate to the High Power (40x) objective and use the Fine Focus Knob for clarity. | The user rotates the virtual nose piece and adjusts the Fine Focus Knob to sharpen the image in the virtual eyepiece. |
| **5. Visualizing the Light Path** | *(Cannot be performed — concept is unobservable physically.)* | The user clicks the **“See Light Path”** button to view a red light ray traveling from the source, through the specimen, to the eyepiece. |
| **6. Illumination Adjustment** | Adjust the Iris Diaphragm or rheostat to improve image contrast and brightness. | The user interacts with the virtual intensity knob or slider to adjust light levels and observe brightness changes on the specimen. |
